입원 환자 데이터를 입력해 생사 여부 확인을 위한 자료 입력

AGE : 나이

SEX : 성별

RACE : 인종

SER : 중환자 치료실에서 받은 치료

CAN : 암 존재 여부

INF : 중환자 치료실에서의 감염 여부

CPR : 중환자 치료실 도착 전 CPR여부

HRA : 중환자 치료실에서의 심박수

예 ) AGE  SEX  RACE  SER  CAN  INF  CPR  HRA
     27   1     1     0    0    1    0    88
AGE SEX RACE SER CAN
CRN INF CPR HRA
